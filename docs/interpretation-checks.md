# Questions for the post-formal review

The simulations and the 0.99 controls have already been interpreted. These diagnostics use their archived coefficients and are exploratory. The original primary event remains the one in the [protocol](protocol.md).

1. **Does the phrase “low overlap” drive the headline?** Cross all three originally specified RMSE-gap tolerances (0.02, 0.05, 0.10) with variable Jaccard cutoffs 0.25, 0.50 and 0.75. Compute numerator and denominator for both the joint and conditional event for each method and condition. Retain the continuous conditional distribution for Lasso across all eight main cells. Do not choose a new primary cutoff.
2. **How do differences in coefficients translate into differences in predictions?** For each signal block, project the difference between two original-scale coefficient vectors onto the constant-vector direction and its orthogonal complement. Pool squared lengths over valid pairs and the three signal blocks within each condition and method. Compare the share of squared coefficient distance in within-block contrasts with its share of signal-block prediction disagreement after covariance weighting. Include the null blocks and intercept in a separate identity check against the recorded whole-model disagreement.
3. **Who selected the generating member during a complete swap?** Count complete signal-block substitutions with the true variable selected on exactly one side and with the true variable omitted on both sides. Reconcile the sum with the existing complete-swap counts. There is one generating variable per signal block. The frequency denominator for the complete-swap rate remains all jointly detected signal blocks.
4. **What can the size-matched Elastic Net comparison identify?** Check the eligible sample counts and pair-level interval calculation. Show a single eligible pair as a descriptive observation. Its sampling uncertainty cannot be estimated by resampling that pair.

Use the eight formal cells, the two original controls, and the two exploratory 0.99 controls for the first three diagnostics. Preserve each condition's original valid-pair denominator.
